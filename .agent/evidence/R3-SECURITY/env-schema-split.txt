R3-SECURITY env schema split (src/config/env.ts)
================================================

- serverEnvSchema: NODE_ENV, PORT, DB_*, JWT_SECRET, JWT_EXPIRES_IN,
  CORS_ORIGIN, REDIS_URL, CLOUDFLARE_AI_*, AI_GRADING_TEST_MODE,
  TRUST_PROXY, S3 vars (optional), CLOUDFLARE_AI_TIMEOUT_MS.
- workerEnvSchema: NODE_ENV, DB_*, REDIS_URL, JWT_SECRET,
  CLOUDFLARE_AI_*, AI_GRADING_TEST_MODE, CLOUDFLARE_AI_TIMEOUT_MS.
- validateServerEnv() / validateWorkerEnv() entry points (validateEnv kept
  as an alias for the old name).
- CORS_ORIGIN=* rejected by refine; JWT_SECRET rejects the REPLACE_WITH
  placeholder (fail closed).
