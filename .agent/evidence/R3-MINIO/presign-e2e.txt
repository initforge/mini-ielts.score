  -d '{"questionId":22,"fileName":"test.webm","fileType":"audio/webm","fileSize":32044}'
HTTP 200

}

== 6. PUT file to presigned URL ==
$ curl -X PUT -H 'Content-Type: audio/webm' --data-binary @/tmp/opencode/r3-test.wav "<uploadUrl>"
HTTP 200
