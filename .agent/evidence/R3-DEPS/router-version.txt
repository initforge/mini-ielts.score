Owner approved FULL UPGRADE path (audit-zero):
  react 18.3.1 -> 19.2.8, react-dom 18.3.1 -> 19.2.8
  react-router-dom 7.18.2 -> react-router 8.3.0 (react-router-dom removed; imports switched react-router-dom -> react-router in all 14 consumer files)
  recharts 2.15.4 -> 3.10.1 (v2 class-component types incompatible with @types/react 19)
  lucide-react 0.300.0 -> 1.28.0 (v0.300.0 peer react ^18 only)
Tradeoffs: React major upgrade (18->19); react-router 8.3.0 engines node >=22.22.0 (build-time only); react-router-dom package no longer used (v8 consolidates into react-router).
GHSA-qwww-vcr4-c8h2 is RSC-mode-only and was never exploitable in this client-only SPA; the audit-zero state is now achieved regardless.
