## 1. N1 MEDIUM — rate-limit identity spoof (cf-connecting-ip gated)
- File: anish-toeic-web-services/src/server.ts:33-41 (function clientIp)
- Before: read req.headers['cf-connecting-ip'] UNCONDITIONALLY; only net.isIP validated; used regardless of TRUST_PROXY.
- After:
  ```ts
  function clientIp(req: express.Request): string {
    if (env.TRUST_PROXY === 'true') {           // gate: trusted reverse proxy only
      const cfIp = req.headers['cf-connecting-ip'];
      if (typeof cfIp === 'string' && net.isIP(cfIp) > 0) return cfIp;  // still validate literal
    }
    return req.ip || 'unknown';
  }
  ```
- Live proof (see health.txt): 3 login attempts with different spoofed `cf-connecting-ip` (1.2.3.4 / 5.6.7.8 / 9.9.9.9) under TRUST_PROXY=false → RateLimit-Remaining decremented 18→17→16 (single shared bucket) — spoofed header ignored.

## 2. N2 MEDIUM — nginx header inheritance dropped security headers on index.html
- File: nginx/nginx.conf
- Before: nested `location = /index.html { add_header Cache-Control "no-cache, no-store, must-revalidate"; }` (was lines ~119-121). Any add_header in a location suppresses inherited server-level add_headers → index.html served with Cache-Control ONLY, no CSP/HSTS/X-Frame-Options/nosniff.
- After:
  - Removed the nested `location = /index.html` block entirely.
  - Declared `add_header Cache-Control "no-cache, no-store, must-revalidate";` at server level (nginx/nginx.conf:78) right after the security headers (62-71). index.html now inherits security headers + no-cache.
  - `/assets/` keeps its own add_header "public, immutable" (line 109) — unchanged; locations with their own add_header still win.
- Validation: `nginx` binary not present on this machine → structural review only. See nginx.txt. VPS-only live check: run `nginx -t` after deploy.
