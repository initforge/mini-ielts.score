=============================================
Date: 2026-08-01

File: anish-toeic-web-app/src/modules/mock-exam/pages/MockExamRunnerPage.tsx

Problem: center timer pill was absolutely positioned
  (absolute left-1/2 -translate-x-1/2) inside the header and overlapped the
  header action buttons on small screens.

Fix: the pill container is now hidden below the md breakpoint:
  class changed from "absolute left-1/2 transform -translate-x-1/2 flex items-center gap-3 pointer-events-none z-[1]"
  to       "absolute left-1/2 transform -translate-x-1/2 hidden md:flex items-center gap-3 pointer-events-none z-[1]"

The md:flex restores it on >=768px screens. Below md the timer is not shown;
countdown still runs and expiry auto-submit is unaffected (deadline/tick live
in the zustand store, not the DOM).
