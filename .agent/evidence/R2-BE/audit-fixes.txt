TASK 1 — AUTH COOKIE-PRIMARY
- anish-toeic-web-services/src/routes/auth.routes.ts
  * :74  register 201 response: removed `token` field; body = { user } only.
  * :122 login 200 response: removed `token` field; body = { user } only.
  * setAuthCookie unchanged: HttpOnly, sameSite=lax, secure=production, path=/,
    maxAge=7d. Cookie remains the only place the JWT travels.

  * removed `localStorage.setItem('token', data.token)` (was :22).
  * POST goes through api instance which now sets withCredentials (api.ts).
  Why: never persist a session token in localStorage (XSS-readable).
- anish-toeic-web-app/src/api.ts
  * removed request interceptor that read localStorage 'token' and injected
    Authorization: Bearer.
  * axios instance now sets `withCredentials: true` so the httpOnly cookie is
    sent on every request.
- anish-toeic-web-services/src/middlewares/auth.middleware.ts
  * UNCHANGED — already accepts Bearer header OR `token` cookie (extractToken
    :31-39), never logs the token. Kept for test/defensive compat per INJ-003.
